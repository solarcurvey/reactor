# Guardian — can / cannot

The Guardian is the only privileged security authority. Immutable address (production: a Safe). Brake pedal, not steering wheel.

## Can

Pause launches, Keeper, trading. Replace Keeper. Replace Launch Signer. Add/quarantine **external** quotes. Approve adapters. Authorize/deprecate factory versions for **new** launches. Permanently lock a ticker (judgment, not an oracle). One-shot genesis binds.

## Cannot

Withdraw LP. Redirect pots. Change 3.5% or 2/1/0.5. Flip Standard↔Rewards. Mint, seize, blacklist. Set Top-10. Upgrade. Wallet fee-exemption.

Compromise can halt the product. It cannot steal official LP. See `GUARDIAN_MODEL.md` and `PRIVILEGE_MAP.md`.
